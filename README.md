# CS340_portfolio

I write programs by keeping each part focused, using clear naming, and avoiding repeated code. The CRUD Python module made the database operations reusable and easier to maintain, while keeping the dashboard code cleaner. I could reuse the module in other projects that need to create, find, update, or delete database records.

For the Grazioso Salvare project, I started with the client’s needs and connected them to the data and dashboard features that would help meet those needs. This felt more like solving a real-world problem than some earlier assignments because the database and dashboard had to work together for a specific user. In the future, I would clarify requirements early, organize the data around them, and test that the results match what the client needs.

Computer scientists use technology to solve practical problems, and that matters because thoughtful software can save people time and help them make better decisions. This dashboard could help Grazioso Salvare find and review animals that match its needs more efficiently, supporting its work to help animals.
